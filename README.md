# Personal Portfolio Website

This is a personal portfolio website created as part of the CS50x course (Week 8).

## Project Structure

```
.
├── assets/
│   ├── css/         # CSS stylesheets
│   ├── images/      # Image files
│   └── js/          # JavaScript files
├── pages/           # HTML pages
│   ├── about.html   # About me page
│   ├── contact.html # Contact page
│   └── projects.html# Projects showcase
├── index.html       # Homepage
└── README.md        # Project information
```

## Features

- Responsive design using Bootstrap
- Interactive project gallery with hover effects
- Image flip animation on homepage
- Clean and minimalist design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## How to Run

Simply open `index.html` in any modern web browser.
